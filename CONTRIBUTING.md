# Berkontribusi ke ChatGPT Prompt Library for Marketers

Terima kasih sudah mau menambahkan prompt! Setiap prompt yang berkualitas akan membantu ribuan marketer.

---

## Standar Kualitas Prompt

### ✅ Prompt yang Diterima
- **Spesifik** — bukan generic, memberikan instruksi yang jelas ke AI
- **Actionable** — menghasilkan output yang langsung bisa digunakan
- **Tested** — sudah dicoba dan hasilkan output berkualitas
- **Formatted** — menggunakan format standar repo ini

### ❌ Prompt yang Ditolak
- Terlalu generik ("buatkan konten marketing")
- Duplikat dari prompt yang sudah ada
- Menyebarkan misinformasi atau manipulatif secara tidak etis

## Cara Submit Prompt

```bash
# 1. Fork repo ini
# 2. Buat branch
git checkout -b prompt/nama-prompt-baru

# 3. Tambahkan prompt ke file yang tepat di prompts/
# 4. Commit
git commit -m "feat: tambah prompt [nama] ke kategori [kategori]"

# 5. Push dan buat Pull Request
git push origin prompt/nama-prompt-baru
```

### Format Standar Prompt

```markdown
## [NOMOR]. NAMA PROMPT

[Konteks penggunaan singkat]

```
PERAN: [...]
TUGAS: [...]
INPUT: [variabel yang perlu diisi]
OUTPUT: [apa yang dihasilkan]
```

**Contoh Output:**
[tunjukkan contoh output nyata]
```
