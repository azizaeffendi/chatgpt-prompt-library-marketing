# Berkontribusi ke ChatGPT Prompt Library for Marketers

Terima kasih sudah mau menambahkan prompt! Setiap prompt yang berkualitas akan membantu ribuan marketer.

---

## Standar Kualitas Prompt

Prompt yang diterima harus memenuhi kriteria BERIKUT:

### ✅ Prompt yang Diterima
- **Spesifik** — bukan generic, memberikan instruksi yang jelas ke AI
- **Actionable** — menghasilkan output yang langsung bisa digunakan
- **Tested** — sudah dicoba dan hasilkan output berkualitas
- **Formatted** — menggunakan format standar repo ini
- **Categorized** — masuk ke kategori yang tepat

### ❌ Prompt yang Ditolak
- Terlalu generik ("buatkan konten marketing")
- Menghasilkan output yang perlu banyak editing
- Duplikat dari prompt yang sudah ada
- Menyebarkan misinformasi atau manipulatif secara tidak etis

## Format Standar Prompt

```markdown
## [NOMOR]. NAMA PROMPT YANG DESKRIPTIF

[Opsional: 1-2 kalimat tentang konteks penggunaan]

```
PERAN/KONTEKS: [...]

TUGAS: [...]

INPUT YANG DIPERLUKAN:
- [Variabel 1]: [deskripsi]
- [Variabel 2]: [deskripsi]

OUTPUT YANG DIHARAPKAN:
[format dan apa yang dihasilkan]
```

**Contoh Output:**
[tunjukkan contoh output nyata]

**Tips Optimasi:**
[1-2 tips untuk hasil lebih baik]
```

## Cara Submit Prompt

### 1. Fork dan Clone
```bash
git clone https://github.com/YOUR_USERNAME/chatgpt-prompt-library-marketing.git
cd chatgpt-prompt-library-marketing
```

### 2. Buat Branch
```bash
git checkout -b prompt/nama-prompt-baru
```

### 3. Tambahkan Prompt
- Pilih file yang tepat di folder `prompts/`
- Ikuti format standar di atas
- Pastikan sudah tested

### 4. Commit dan PR
```bash
git commit -m "feat: tambah prompt [nama] ke kategori [kategori]"
git push origin prompt/nama-prompt-baru
```

Buat Pull Request dengan deskripsi:
- Prompt apa yang ditambahkan
- Untuk use case apa
- Contoh output yang dihasilkan
