## Quick Prompts

### Meta Ads Copy Instan
```
Tulis iklan Facebook/Instagram untuk [PRODUK]. Target: [deskripsi audiens].
Buat: Primary text (150 kata), Headline (27 karakter), Description (27 karakter).
Objective: [Traffic/Conversion/Awareness]. Tone: [urgent/soft/educational].
```

### Google Ads Headlines (15 Variasi)
```
Buat 15 headline Google Ads untuk keyword "[KEYWORD TARGET]".
Setiap headline max 30 karakter. Sertakan keyword di minimal 5 headline.
Produk: [nama]. USP: [keunggulan utama].
```
