## Content Pillar Framework

```
PILLAR 1: EDUKASI     → Ajarkan sesuatu yang berharga
PILLAR 2: INSPIRASI   → Motivasi dan storytelling
PILLAR 3: HIBURAN     → Relatable, humor, entertaining
PILLAR 4: PROMOSI     → Produk, layanan, penawaran
PILLAR 5: KOMUNITAS   → UGC, Q&A, engagement

Rasio ideal: 3:2:2:2:1
```

## Quick Prompts

### Content Strategy 90 Hari
```
Buat content strategy 90 hari untuk [BISNIS/BRAND].
Sertakan: content pillars, platform priority, posting frequency,
KPI per bulan, dan bagaimana konten berubah dari bulan 1 ke bulan 3
(awareness → consideration → conversion).
```

### Repurposing 1 Konten Jadi 10
```
Saya punya [JENIS KONTEN: artikel blog / video YouTube / podcast episode] tentang [TOPIK].
Buat 10 cara merepurpose konten ini ke format berbeda:
Instagram carousel, TikTok script, Twitter thread, LinkedIn post, email newsletter,
YouTube Shorts, WhatsApp broadcast, infografis, quote card, dan podcast clip.
```
