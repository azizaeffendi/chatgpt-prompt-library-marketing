## Quick Prompts

### Growth Experiment Roadmap
```
Buat 20 growth experiment untuk [BISNIS] yang bisa dijalankan dalam [timeframe].
Untuk setiap experiment: hipotesis, cara jalankan, metric yang diukur,
waktu yang dibutuhkan, biaya estimasi, dan potensi impact (low/medium/high).
Urutkan dari highest-impact + lowest-effort.
```

### Referral Program Design
```
Rancang program referral untuk [PRODUK/LAYANAN].
Sertakan: mekanisme reward (untuk referrer dan referee),
cara promosi program, tools yang dibutuhkan, KPI sukses,
dan contoh pesan yang digunakan untuk share.
```

### Viral Marketing Kampanye
```
Buat konsep kampanye viral untuk [BRAND] di Indonesia.
Target platform: [platform]. Target audiens: [deskripsi].
Konsep harus: mudah dipartisipasi, punya element shareable,
terhubung dengan produk secara natural, dan bisa diukur.
Sertakan: nama kampanye, mekanisme, timeline, dan KPI.
```
