# 🎵 TikTok Content Prompts

TikTok adalah platform dengan organic reach terbesar saat ini. Kuasai format-nya.

---

## 1. TIKTOK VIDEO SCRIPT — HOOK-BODY-CTA

```
Tulis script TikTok [DURASI: 15/30/60] detik untuk [TOPIK/PRODUK].

AKUN: [niche akun Anda]
TARGET AUDIENS: [usia, interest]
TUJUAN: [followers / awareness / penjualan / traffic ke link bio]
FORMAT: [talking head / voice over / text on screen / tutorial]

SCRIPT:

[0-2 DETIK] — THE HOOK (paling kritis — tentukan apakah orang lanjut atau skip):
Pilih salah satu hook style:
A) VISUAL HOOK: tunjukkan hasil akhir terlebih dahulu ("Ini hasilnya sebelum vs sesudah")
B) AUDIO HOOK: kalimat pertama yang buat bingung/penasaran ("Saya hampir bangkrut karena...")
C) TEXT HOOK: teks besar di layar yang controversial atau curious
D) ACTION HOOK: langsung tunjukkan aksi yang menarik perhatian

[2-50 DETIK] — THE BODY:
- Deliver value yang dijanjikan hook
- Keep it concise — buang semua filler words
- Setiap 5-7 detik harus ada sesuatu yang baru (visual change atau info baru)
- Gunakan transition yang dinamis

[50-60 DETIK] — THE HOOK RETENTION:
Katakan sesuatu yang membuat mereka HARUS menonton lagi atau komentar
"Dan satu hal lagi yang tidak saya ceritakan di awal..."

MICRO-CTA (last 2 seconds):
"Follow untuk tips lebih" / "Komentar kalau kamu setuju" / "Save ini untuk nanti"

CAPTION (pisah):
1-2 kalimat + pertanyaan untuk komentar + 3-5 hashtag (#fyp #[niche])
```

## 2. TIKTOK ADS SCRIPT — PERFORMANCE MARKETING

```
Tulis script TikTok Ads untuk [PRODUK/LAYANAN].

OBJECTIVE: [Traffic / Conversions / App Install / Lead Generation]
BUDGET: [budget/hari]
TARGET AUDIENCE: [usia, gender, interest, behavior]
DURASI: [15 / 30 / 60 detik]
TONE: [entertaining / educational / testimonial / ugc-style]

STRUKTUR TIKTOK ADS (berbeda dari konten organik):

[0-3 DETIK] NATIVE HOOK — harus terasa seperti konten organik, bukan iklan:
- Jangan mulai dengan logo atau brand name
- Mulai dengan situasi relatable atau problem
- Audio original > background music untuk authenticity

[3-20 DETIK] PROBLEM + SOLUTION:
- Identify masalah yang target audience kenal
- Introduce produk sebagai solusi secara natural
- Tunjukkan produk in-action, bukan sekadar tampilan

[20-25 DETIK] SOCIAL PROOF:
- Angka (berapa orang sudah pakai / rating)
- Quick testimoni quote
- Visual hasil nyata

[25-30 DETIK] CTA:
- Spesifik dan urgent: "Klik di bawah sekarang" / "Link di bio, cek sekarang"
- Gunakan on-screen text CTA juga

VARIASI yang perlu dibuat:
- Versi A: Fokus pain point
- Versi B: Fokus aspirasi/desire
- Versi C: UGC-style (seperti review organik)
```

## 3. TIKTOK CONTENT SERIES STRATEGY

```
Buat strategi konten series TikTok untuk [NICHE/BISNIS].

TUJUAN SERIES: [build audience / educate / sell / entertain]
FREKUENSI TARGET: [X video/minggu]
DURASI PER VIDEO: [15/30/60 detik]

BUAT:

1. SERIES CONCEPT:
Nama series yang catchy + format yang konsisten (hook sama setiap episode)

2. CONTENT BATCHING — 20 VIDEO IDEAS:
Untuk setiap ide: angle unik, hook pembuka, key message

3. POSTING SCHEDULE:
Waktu optimal untuk target audiens + frekuensi ideal

4. HOOK FORMULAS untuk series ini:
3 hook template yang bisa dirotasi agar followers anticipate konten

5. CTA YANG MEMBANGUN AUDIENCE:
Bagaimana setiap video mendorong follower, komentar, dan share

CATATAN: TikTok algorithm lebih menyukai konsistensi dan momentum. Post 3-5x/minggu 
di awal lebih efektif daripada 1x/minggu dengan kualitas sangat tinggi.
```
