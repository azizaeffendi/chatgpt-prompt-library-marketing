## Quick Prompts

### Caption Generator Instan
```
Tulis caption [INSTAGRAM/LINKEDIN] untuk konten tentang [TOPIK].
Bisnis: [nama]. Tone: [santai/profesional/inspiratif].
Sertakan: hook kuat di kalimat pertama, 2-3 paragraf, CTA, dan 20 hashtag relevan.
```

### Content Batch — 30 Hari
```
Buat 30 ide konten untuk [platform] tentang [niche/industri].
Format: [Minggu X - Hari Y | Topik | Format konten | Hook pembuka]
Goal bulan ini: [brand awareness/lead gen/sales].
```
