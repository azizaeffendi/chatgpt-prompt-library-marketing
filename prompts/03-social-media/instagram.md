# 📸 Instagram Content Prompts

Dari caption biasa ke konten yang viral — semua formula ada di sini.

---

## 1. CAPTION GENERATOR LENGKAP

```
PERAN: Kamu adalah social media manager berpengalaman untuk brand [INDUSTRI].

BUAT CAPTION INSTAGRAM untuk:
VISUAL/KONTEN: [deskripsi gambar atau video yang akan diposting]
TUJUAN POST: [brand awareness / engagement / penjualan / edukasi]
TONE BRAND: [fun & playful / profesional / inspiratif / edukatif]
TARGET AUDIENS: [deskripsi followers Anda]

STRUKTUR CAPTION:
1. HOOK (kalimat pertama — KUNCI untuk menghentikan scroll):
   - Maksimal 125 karakter sebelum "lihat selengkapnya"
   - Gunakan: pertanyaan mengejutkan / fakta menarik / pernyataan bold

2. BODY (2-4 paragraf):
   - Expand hook dengan story atau nilai
   - Sertakan relatable moment atau insight
   - Sisipkan emoji secara natural (tidak berlebihan)

3. CALL TO ACTION:
   - Spesifik: "Simpan post ini untuk referensi nanti" / "Tag teman yang butuh ini"
   - Tanya: "Kamu lebih suka mana? Komen di bawah!"

4. HASHTAG (pisahkan dari caption):
   - 5 hashtag niche kecil (di bawah 100K posts) untuk jangkauan tepat
   - 10 hashtag medium (100K-1M posts)
   - 5 hashtag besar (1M+ posts) untuk exposure
   - Hindari hashtag banned

OUTPUT: Buat 2 versi caption (pendek 150 kata & panjang 300 kata) + 20 hashtag.
```

## 2. INSTAGRAM CAROUSEL — 10 SLIDE FRAMEWORK

```
Buat script carousel Instagram 10 slide untuk topik: [TOPIK]

KONTEKS:
- Akun: [deskripsi akun Anda]
- Tujuan: [edukasi / lead gen / viral]
- Target: [audiens]

STRUKTUR SLIDE (satu slide = 1-2 kalimat pendek + visual direction):

SLIDE 1 — COVER (Hook yang memaksa swipe):
Judul: [bold statement atau pertanyaan]
Visual: [deskripsi desain cover]

SLIDE 2 — PROMISE:
"Di carousel ini kamu akan belajar: [preview value]"

SLIDE 3-8 — KONTEN INTI:
[6 poin utama, masing-masing 1 insight actionable]

SLIDE 9 — INSIGHT TERKEJUT / BONUS TIP:
[Sesuatu yang tidak terduga — membuat mereka merasa dapat lebih]

SLIDE 10 — CTA:
[Ajakan yang spesifik: follow, simpan, DM, kunjungi link bio]

CAPTION untuk carousel ini: [hook + body + CTA + hashtag]

JUDUL ALT TEXT untuk setiap slide: [untuk aksesibilitas dan SEO Instagram]
```

## 3. INSTAGRAM REELS SCRIPT

```
Tulis script Reels Instagram berdurasi [15/30/60] detik untuk [TOPIK].

FORMAT VIDEO: [talking head / B-roll / text on screen / mix]
TONE: [educational / entertaining / inspirational / promotional]

STRUKTUR SCRIPT:

[0-3 detik] HOOK VISUAL + AUDIO:
Aksi fisik atau kata-kata pertama yang membuat orang TIDAK skip
"Contoh: (langsung tunjukkan hasil akhir) 'Ini hasilnya setelah 30 hari...'"

[3-25 detik] KONTEN INTI:
- Poin 1: [insight / step / tip]
- Poin 2: [insight / step / tip]
- Poin 3: [insight / step / tip]

[25-30 detik] HOOK KEDUA (retention trick):
"Dan yang paling penting adalah..." → membuat orang tonton sampai akhir

[Detik terakhir] MICRO-CTA:
"Simpan ini" atau "Follow untuk tips lainnya"

CAPTION pendek untuk Reels: [max 150 kata]
AUDIO YANG DIREKOMENDASIKAN: [tipe musik / trending sound / voiceover]
```

## 4. INSTAGRAM STORIES — SEQUENCE 5 SLIDE

```
Buat story sequence 5 slide yang membangun engagement:

TUJUAN STORY: [awareness / tanya jawab / promo / behind the scene]
TEMA: [topik atau momen]

SLIDE 1 — OPENING (menarik perhatian):
Format: [foto / boomerang / video pendek]
Teks: [max 3 kata, ukuran besar]
Sticker: [polling / pertanyaan / countdown / slider]

SLIDE 2 — BUILD UP:
[Expand cerita atau konteks]
Interactive element: [polling dengan 2 pilihan yang relatable]

SLIDE 3 — VALUE INTI:
[Satu insight atau informasi utama]
Desain: [simple, text dominan atau gambar ekspresif]

SLIDE 4 — SOCIAL PROOF / CREDIBILITY:
[Screenshot testimoni / angka / achievement]

SLIDE 5 — CTA:
[Swipe up link / DM / visit profile / share story ini]
Sticker: [link / mention / countdown]

TIPS: Tambahkan "tap to reveal" atau polling di setiap slide untuk tingkatkan engagement rate.
```

## 5. CONTENT CALENDAR — 30 HARI INSTAGRAM

```
Buat konten calendar 30 hari untuk akun Instagram [NICHE/INDUSTRI].

INFORMASI AKUN:
- Followers saat ini: [jumlah]
- Goal bulan ini: [+X followers / X leads / X sales]
- Posting frequency: [1x/hari / 2x/hari / 3x/minggu]
- Format yang bisa dibuat: [foto / carousel / reels / stories / live]

BUAT JADWAL 30 HARI:

Format tabel:
| Tanggal | Format | Topik/Angle | Hook | Tujuan | Hashtag Type |
|---------|--------|-------------|------|---------|--------------|

DISTRIBUSI KONTEN (80/20 rule):
- 80% value content: edukasi, hiburan, inspirasi
- 20% promotional: produk, layanan, CTA pembelian

CONTENT PILLARS (pilih 3-4):
[ ] Edukasi/Tips
[ ] Behind the scenes
[ ] Testimoni/Social proof
[ ] Personal story
[ ] Trending/Viral participation
[ ] Product showcase
[ ] Community/UGC repost
```

## 6. PROMPT UNTUK JUALAN DI INSTAGRAM TANPA TERKESAN JUALAN

```
Buat caption promosi yang TIDAK terasa seperti iklan untuk [PRODUK/LAYANAN].

PRODUK: [nama + harga]
MANFAAT UTAMA: [top 3 benefit]

GUNAKAN SALAH SATU FRAMEWORK:

FRAMEWORK 1 — THE STORY SELL:
Ceritakan kisah nyata pelanggan yang berhasil.
Struktur: Masalah sebelum → Pertemuan dengan produk → Transformasi setelah

FRAMEWORK 2 — THE EDUCATIONAL SELL:
Berikan value dulu, sebut produk di akhir.
"5 cara mengatasi [masalah]... [Tips 1-4]... [Tips 5: gunakan produk kami]"

FRAMEWORK 3 — THE COMPARISON SELL:
Bandingkan "cara lama" vs "cara baru dengan produk kami"

FRAMEWORK 4 — THE BEHIND THE SCENES:
Tunjukkan proses pembuatan/cara kerja produk.
Orang tertarik dengan cara sesuatu dibuat.

Output: Caption + hashtag + saran visual yang mendukung pesan.
```
