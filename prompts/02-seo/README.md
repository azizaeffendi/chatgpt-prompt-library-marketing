## Quick Win SEO Prompts

### Keyword Cluster Instan
```
Buat keyword cluster untuk topik utama "[TOPIK]" di industri [INDUSTRI].
Organisasikan dalam:
- 1 pillar keyword (volume tinggi, kompetisi tinggi)
- 5 supporting keywords (long-tail, lebih mudah ranking)
- 10 question keywords (untuk featured snippet)
- 5 local keywords (jika bisnis lokal)

Untuk setiap keyword: estimasi intent (informational/commercial/transactional).
```

### Meta Description Generator
```
Tulis meta description untuk halaman "[JUDUL HALAMAN]".
Keyword utama: [keyword]
URL: [url]
Max 155 karakter. Sertakan CTA dan keyword di awal.
Buat 3 variasi untuk A/B test.
```
