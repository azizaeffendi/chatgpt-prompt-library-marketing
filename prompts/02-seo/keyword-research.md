# 🔑 Keyword Research Prompts

Temukan keyword yang tepat — bukan hanya yang banyak dicari, tapi yang menghasilkan konversi.

---

## 1. MASTER KEYWORD RESEARCH PROMPT

```
PERAN: Kamu adalah SEO specialist dengan 10+ tahun pengalaman di industri [INDUSTRI].

TUGAS: Lakukan keyword research mendalam untuk bisnis berikut:

BISNIS: [nama & deskripsi singkat]
PRODUK/LAYANAN: [apa yang dijual]
TARGET LOKASI: [Indonesia / kota tertentu / internasional]
KOMPETITOR UTAMA: [nama 2-3 kompetitor]

HASILKAN:
1. PILLAR KEYWORDS (3-5 keyword):
   - Keyword utama dengan volume tinggi
   - Prediksi tingkat kesulitan (mudah/sedang/sulit)
   - Search intent (informational/navigational/commercial/transactional)

2. LONG-TAIL KEYWORDS (20 keyword):
   - Spesifik, 4-7 kata
   - Lebih mudah ranking, konversi lebih tinggi
   - Kategorikan per intent

3. QUESTION KEYWORDS (15 keyword):
   - Dimulai dengan: Apa, Bagaimana, Mengapa, Berapa, Kapan
   - Ideal untuk featured snippet dan voice search

4. BUYER INTENT KEYWORDS (10 keyword):
   - Kata-kata yang menandakan siap beli: "beli", "harga", "terbaik", "rekomendasi", "vs", "review"

5. LOCAL SEO KEYWORDS (jika relevan):
   - "[layanan] + [kota]" variasi
   - "dekat saya", "terdekat" kombinasi

FORMAT OUTPUT: Tabel markdown dengan kolom: Keyword | Intent | Estimasi Difficulty | Prioritas
```

## 2. COMPETITOR KEYWORD GAP ANALYSIS

```
Analisis keyword gap untuk membantu saya menemukan peluang yang dilewatkan kompetitor.

WEBSITE SAYA: [domain.com]
KOMPETITOR A: [domain-a.com]
KOMPETITOR B: [domain-b.com]

TOPIK INDUSTRI: [industri/niche]

Identifikasi:
1. QUICK WINS: Keyword yang kompetitor rank tapi saya belum ada kontennya
2. CONTENT GAPS: Topik penting yang tidak ada satupun yang bahas dengan baik
3. LONG-TAIL OPPORTUNITIES: Keyword spesifik dengan kompetisi rendah
4. TRENDING TOPICS: Topik yang naik daun di industri ini

Untuk setiap peluang, berikan:
- Keyword
- Alasan mengapa ini adalah peluang
- Jenis konten yang sebaiknya dibuat (artikel / landing page / FAQ / video)
- Estimasi waktu untuk ranking
```

## 3. KEYWORD MAPPING UNTUK KONTEN

```
Buat keyword map untuk website [DOMAIN/BISNIS].

STRUKTUR WEBSITE:
- Homepage: [topik utama]
- Halaman Layanan: [list layanan]
- Blog: [topik-topik yang akan dibahas]
- About: [tentang perusahaan]

UNTUK SETIAP HALAMAN, tentukan:
1. PRIMARY KEYWORD (1 keyword utama)
2. SECONDARY KEYWORDS (3-5 keyword pendukung)
3. LSI KEYWORDS (7-10 keyword terkait secara semantik)
4. INTERNAL LINKING OPPORTUNITIES (halaman mana yang bisa saling link)

Tujuan: Setiap halaman website harus "own" keyword spesifik tanpa kanibalisasi.
```

## 4. FEATURED SNIPPET KEYWORD STRATEGY

```
Cari peluang featured snippet untuk [INDUSTRI/NICHE].

Featured snippet adalah "posisi 0" di Google — kotak jawaban di atas semua hasil.

Buat list 20 pertanyaan yang:
1. Sering dicari orang di [industri]
2. Jawabannya bisa diberikan dalam 40-60 kata (paragraph snippet)
3. Atau dalam format list/tabel (list snippet)

Untuk setiap pertanyaan:
- Tulis contoh jawaban yang berpotensi masuk featured snippet (40-60 kata)
- Tentukan format: paragraph / numbered list / bullet list / table
- Rekomendasikan heading H2/H3 yang ideal

KONTEKS BISNIS: [deskripsi singkat bisnis Anda]
```

## 5. KEYWORD UNTUK KONTEN LOKAL INDONESIA

```
Bantu saya temukan keyword untuk bisnis lokal di Indonesia:

BISNIS: [jenis bisnis]
KOTA/AREA: [kota atau wilayah]
BAHASA TARGET: Bahasa Indonesia

Hasilkan keyword dalam 3 bahasa/dialek:
1. BAHASA INDONESIA FORMAL: kata-kata baku yang diketik di Google
2. BAHASA GAUL / COLLOQUIAL: yang orang benar-benar ketik
3. KOMBINASI: mix antara keyword + nama daerah

Contoh untuk "jasa website":
- Formal: "jasa pembuatan website profesional Jakarta"
- Gaul: "bikin website murah Jakarta" / "jasa website terpercaya"
- Lokal: "developer website Kemang" / "web developer BSD Tangerang"

Buat 30 variasi untuk bisnis saya.
```
